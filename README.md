Descrição do Projeto
Site pessoal de currículo/portfólio desenvolvido em HTML5 e CSS3 puro, sem uso de JavaScript ou frameworks.

Como visualizar
Abra o ficheiro `index.html` no navegador.

Páginas do Site-index.html- Página inicial com apresentação pessoal, foto, tagline e botão para contacto.

sobre.html - Currículo com formação, experiência, competências e tabela de proficiência.
ortfolio.html - Projetos em cards com CSS Grid.
hobbies.html - Hobbies organizados com Flexbox.
-contacto.html - Formulário de contacto com validação HTML5.

Principais Tags HTML Utilizadas
- `<header>` - Cabeçalho do site
- `<nav>` - Menu de navegação
- `<main>` - Conteúdo principal
- `<section>` - Seções de conteúdo
- `<article>` - Conteúdo independente
- `<aside>` - Conteúdo complementar
- `<footer>` - Rodapé
- `<figure>` e `<figcaption>` - Imagens com legenda
- `<table>` com `<thead>` e `<tbody>` - Tabela de competências
- `<video>` e `<audio>` - Multimédia nativa
- `<fieldset>` e `<legend>` - Agrupamento de formulário

Principais Recursos CSS Utilizados
-Variáveis CSS (`:root`) - Cores e espaçamentos
-Flexbox - Menu e página Hobbies
-CSS Grid - Portfólio com `repeat(auto-fit, minmax())`
-Position: sticky - Header fixo ao rolar
- Pseudo-classes - `:hover`, `:focus`, `:nth-child()`
-Pseudo-elementos - `::before` e `::after`
- Transições e Animações - `@keyframes pulse`
-Gradientes e Sombras - `linear-gradient`, `box-shadow`
-Media Queries - Responsividade para tablet e telemóvel
- Unidades relativas - `rem`, `%`, `vw`
